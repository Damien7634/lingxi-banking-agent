# 灵犀银行 · Banking Agent

面向**跨境电商从业者**的全栈智能银行助理演示项目：用户用自然语言即可办理转账、账单分析、汇率避险、供应链金融、物流海关追踪、理财申赎、卡片管理、跨场景守护等业务。

> 本项目由 Kimi 平台构建，演示性质。礼品下单、清算通道、物流/海关对接等为模拟实现，未对接真实商户与核心账务系统。

## 功能

### 跨境电商金融（v2 新增）

- **多币种钱包**：CNY 活期主账户 + USD/EUR 外币钱包，首页总资产自动折人民币汇总
- **汇率避险**：
  - 实时牌价（买/卖双向，带微波动）与外币敞口分析、对冲比例
  - 远期锁汇：约定到期日按锁定汇率结汇/购汇，收取 5% 人民币保证金（冻结）
  - 外汇期权：支付 1.5% 期权费获得到期行权权利，适合回款时点不确定场景
- **供应链金融**：跨境订单贷、海外仓仓单质押贷、出口退税贷、出口信保融资四类产品，按日计息（本金 × 年化 × 天数 / 365），在线申请即时放款、支持提前结清
- **外贸一体化服务**：
  - 物流运单追踪（云途/递四方/顺丰国际/燕文），轨迹时间线与在途状态
  - 海关报关单状态（申报/查验/放行）
  - 出口退税进度跟踪（申报→审核→核准→退付）与退税贷交叉引导

### 核心银行服务

- **智能转账**：按人名/手机号/备注识别收款人（多候选自动澄清）、实时转账、定时转账、AA 收款拆分
- **账单分析**：月度/年度收支分类统计、环比、商户排行；规则引擎识别异常交易（凌晨大额、陌生对手方大额、高频异常）
- **理财**：风险测评 → 按风险等级推荐与对比产品（含适当性硬校验）→ 一键申购/赎回
- **卡片管理**：申请借记卡/信用卡、额度调整、冻结/解冻、挂失、交易限制、线上支付开关
- **跨场景守护（生日守护）**：检测联系人生日 → 生日当月自动锁定活期专款 → 生日前 N 天自动下单鲜花和蛋糕 → 生日当天送达并解锁余款（状态机：armed → locked → ordered → done）
- **Banking Agent**：LLM 工具调用（31 个工具），SSE 流式对话，大额/不可逆操作先确认，全部对话持久化

## 技术栈

- 前端：React 19 + TypeScript + Vite + Tailwind CSS + shadcn/ui + Recharts（移动端优先，桌面端居中手机栏）
- 后端：Hono + tRPC 11（端对端类型安全）
- 数据库：MySQL + Drizzle ORM
- AI：AI SDK（`streamText` + 工具调用），模型经网关接入，凭证仅服务端持有

## 本地运行

```bash
npm install
cp .env.example .env   # 填写 DATABASE_URL 等
npm run db:push          # 同步表结构
npx tsx db/seed.ts       # 写入演示数据（账户/钱包/牌价/合约/贷款/运单/报关/退税/交易/联系人/理财/卡片）
npm run dev              # http://localhost:3000
```

生产构建：`npm run build && npm start`

## 目录结构

```
api/            # Hono + tRPC 后端
  agent/        # Agent 工具集（31 个 LLM 工具）
  lib/          # 账务 helper、生日守护状态机、AI 客户端
  routers/      # 账户/转账/账单/外汇/供应链金融/外贸/理财/卡片/场景 tRPC 路由
  routes/       # Agent SSE 对话 REST 端点
contracts/      # 前后端共享类型
db/             # Drizzle schema（19 张表）与演示种子数据
src/pages/      # 首页 / 跨境金融(汇率避险·供应链金融·理财) / 外贸 / 账单 / 小犀 / 卡包
```
